Задание 1, задача 5

Дан набор целых чисел, количество которых делится на 3. Заполнить список L исходными
числами, вывести вначале первую треть элементов списка L в исходном порядке, затем вторую
треть элементов в обратном порядке, а затем последнюю треть (также в обратном порядке).

Алгоритм: 

- считать размер списка n и сами элементы

- с помощью итератора вывести первую треть в прямом порядке
- сдвинуть итератор на начало второй трети и вывести её элементы в обратном порядке (двигаясь от конца трети к началу)
- вывести последнюю треть в обратном порядке
