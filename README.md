Задание 1, задача 5

Дан набор целых чисел, количество которых делится на 3. Заполнить список L исходными
числами, вывести вначале первую треть элементов списка L в исходном порядке, затем вторую
треть элементов в обратном порядке, а затем последнюю треть (также в обратном порядке).

Алгоритм: 
- считать размер списка n и сами элементы
- вычислить размер одной трети: third = n / 3
- с помощью итератора вывести первую треть в прямом порядке
- сдвинуть итератор на начало второй трети и вывести её элементы в обратном порядке
- вывести последнюю треть в обратном порядке

перед пятым с конца элементом списка последние 5 элементов дека в обратном порядке.
Использовать один вызов функции-члена insert.

Алгоритм:

- одним вызовом функции insert вставить элементы: l.insert(l_pos, temp.begin(), temp.end());.

Задание 3, задача 11

Даны два списка L1 и L2 с одинаковым количеством элементов N. Получить в списке L2
комбинированный набор элементов исходных списков вида A1, B1, A2, B2, A3, B3, …, AN, BN, где
Ai обозначают элементы исходного списка L1, а Bi — элементы исходного списка L2. Для этого
использовать итераторы i1 (для списка L1) и i2 (для списка L2), связав их с первым элементом
соответствующего списка. В цикле, который должен повторяться N раз, вызывать функциючлен splice для списка L2 с первым параметром ++i2 и третьим параметром i1++.

Алгоритм: 
- создать итераторы auto i1 = l1.begin(); и auto i2 = l2.begin();.
- в цикле N раз вызывать функцию splice для перемещения очередного элемента из L1 в L2: l2.splice(++i2, l1, i1++);.

Задание 10, задача 1 

Дан вектор V. Определить количество повторений каждого числа в векторе V и вывести все
различные элементы вектора V вместе с количеством их повторений (в порядке возрастания
значений элементов); количество повторений выводить сразу после значения
соответствующего элемента. Использовать вспомогательное отображение M (класс map),
ключами которого являются различные элементы вектора V, а значениями — количество
повторений этих элементов. При заполнении отображения M не использовать условные
конструкции (достаточно операций индексирования [] и инкремента). Элементы вектора V (при
заполнении отображения M) и элементы отображения M (при выводе полученных результатов)
перебирать в цикле с параметром-итератором соответствующего контейнера

Алгоритм: 

- ввести размер вектора и заполнить его через итераторы.
- создать std::map<int, int>.
- в цикле по вектору инкрементировать значение для каждого элемента: ++m[*it];.
- вывести элементы map (автоматически упорядочены по возрастанию ключа), перебирая их итератором.
